# 青岛栈桥海洋环境监测大屏

面向栈桥海水浴场的实时海洋与气象数据大屏，包含潮汐、天气、风况、浪高、气象预警和钉钉组合规则通知。台风路径模块可隐蔽切换查看最近发送成功的钉钉通知记录。大屏与通知配置页相互独立：

- 大屏：`/`
- 通知配置：`/notification-admin`

## 本地运行

需要 Python 3.10 或更高版本，无需安装额外 Python 依赖。

```bash
python OceanWindow_optimized.py --server
```

默认访问地址为 `http://127.0.0.1:5051/`。可通过环境变量 `PORT` 修改端口。

## 数据更新频率

| 模块 | 大屏更新频率 | 说明 |
| --- | --- | --- |
| 页面时钟 | 1 秒 | 页面不可见时暂停 |
| 潮汐源数据 | 1 小时 | 潮段状态和进度每分钟在本地重新计算 |
| 潮汐曲线 | 6 小时 | “现在”标线每分钟更新 |
| 天气、风况与晚霞评分 | 10 分钟 | 天气模块可切换查看晚霞总分、5项分值和1至5颗小太阳等级；晚霞评分与通知规则共用同一份多点预报缓存 |
| 浴场浪高和水温 | 1 小时 | — |
| 钓鱼评分 | 30 分钟 | 海况模块内切换查看；计算未来24小时评分和推荐时段，服务端缓存30分钟 |
| 青岛近海浪高 | 15 分钟 | 与通知规则的数据缓存周期保持一致；接口异常时直接在大屏显示 |
| 气象与海洋预警 | 5 分钟 | 国家、山东和青岛预警合并显示在顶部预警条；山东预警每轮只请求一次 |
| 台风路径与云图 | 1 小时 | 使用北海预报减灾中心原版页面，显示数据源和最近刷新时间，也可通过模块按钮或大屏刷新按钮立即重载 |
| 钉钉通知记录 | 30 秒 | 仅展示发送成功的记录，按发送时间倒序排列；公开接口不返回快照、错误详情和通道配置 |

各数据模块的标题区域会展示对应数据源和最近更新时间。浏览器标签页切到后台时，定时任务不会继续触发；返回页面后只补刷已经超过上述周期的模块，避免瞬间重复请求。点击“大屏刷新”会立即刷新所有数据模块、台风图和顶部预警条。

天气、态势和海况三个模块采用隐蔽切换方式，不显示标签或切换按钮。标题始终显示当前内容名称；在 1.2 秒间隔内连续点击同一标题 5 次，可分别在“实时天气与风况 / 晚霞评分”“台风路径与云图 / 钉钉通知记录”“海况数据 / 钓鱼评分”之间切换。点击不足 5 次不会改变当前内容。

“实时天气与风况”模块可切换到“晚霞评分”。该视图展示日落方向透光、中高云幕布、能见度与湿度、无降水和雾、西侧低云趋势5项得分，以及总分和小太阳等级。小太阳共5颗：0至24分为1颗、25至44分为2颗、45至69分为3颗、70至84分为4颗、85至100分为5颗；评分数据不足时不点亮小太阳。

“海况数据”模块可切换到“钓鱼评分”。评分面向栈桥岸钓场景，按未来24小时逐小时组合潮流活跃度30分、风况25分、浪高安全20分、降水雷暴15分和清晨/黄昏光照时段10分，并从评分达到65分且无明显风浪风险的小时中选出最多3个互不拥挤的两小时推荐窗口。大风、较大浪或雷暴会触发安全封顶，浪高缺失时不会给出高分；水温因目标鱼种而异，只作现场参考，不纳入通用评分。该结果是出行辅助建议，不代表鱼获保证，现场警戒、浪况和人员安全优先。

只读接口 `/api/fishing?date=YYYY-MM-DD` 返回评分、评分构成、最佳小时、最多3个推荐时段及数据源状态。数据来自 Open-Meteo、全球潮汐预报服务平台和青岛海洋预报，服务端缓存30分钟。

## 钉钉通知规则

通知引擎默认每 60 秒检查一次组合规则。通知侧天气缓存为 10 分钟、近海浪高缓存为 15 分钟，潮汐数据每日更新。同一规则在同一潮段只发送一次；潮段按潮汐数据的基准日期计算，跨午夜不会重复触发，并设有 5 分钟的同规则安全去重窗口。具体启用状态、通知时段、角色、Webhook、规则和发送记录均在 `/notification-admin` 中配置或查看。

通知配置页支持晚霞条件和“一键添加晚霞通知模板”。晚霞评分满分 100 分，由日落方向低云透光条件 35 分、本地中高云幕布 30 分、能见度与湿度 15 分、降水与雾 10 分、西侧低云变化趋势 10 分组成。系统除栈桥本地外，还采样西侧约 75 至 160 公里的 4 个预报点，每 10 分钟更新一次预测：70 分以上为条件较好，45 至 69 分为有一定概率，低于 45 分为概率较低。

通知配置页同时支持钓鱼综合评分、适宜等级、安全状态、推荐时段数量和最佳时段潮汐状态等条件，并提供“一键添加钓鱼评分通知模板”。默认模板要求评分达到 65 分、安全状态正常且至少存在 1 个推荐时段，按自然日最多通知一次；通知正文可插入评分、等级、推荐时段、评分依据、安全提示、潮况、风速和浪高。浪高缺失、大风、大浪或雷暴导致安全状态异常时不会命中默认适宜钓鱼模板。

配置页的五个步骤大模块均可折叠，折叠状态保存在当前浏览器。每条组合规则也可独立收起或展开；按住规则左侧拖拽手柄可调整规则顺序，点击“保存全部设置”后顺序写入服务器配置并在刷新后保持。

默认晚霞模板在评分达到 70 分且进入日落前 30 至 60 分钟时触发，按自然日去重。规则中还可选择初步预测、临近日落和日落后余晖时段，并在通知正文插入晚霞评分、等级、判断依据及日落时间。该评分是数值预报辅助判断，不保证一定出现晚霞；全局通知时段需要覆盖当日日落前后的提醒时间。

大屏通过只读接口 `/api/notification/public-logs` 展示最近发送成功的通知。该接口只返回发送时间、规则名称、角色名称、通知正文和发送状态，不返回事件快照、错误详情、Webhook、签名密钥或手机号。

生产环境应设置管理令牌：

```bash
NOTIFICATION_ADMIN_TOKEN=请替换为高强度随机字符串
```

通知配置和记录默认通过以下路径持久化：

```bash
OCEAN_NOTIFICATION_CONFIG=/data/notification_config.json
OCEAN_NOTIFICATION_DB=/data/ocean_notifications.db
```

## Docker 部署

```bash
docker build -t qingdao-ocean-dashboard:latest .
docker run -d --name ocean-dashboard \
  -p 7860:7860 \
  --env-file /etc/ocean-dashboard.env \
  -v /opt/qingdao-ocean-data:/data \
  --restart unless-stopped \
  qingdao-ocean-dashboard:latest
```

容器内服务端口为 `7860`。请确保宿主机的持久化目录可由容器内 UID `10001` 写入。
